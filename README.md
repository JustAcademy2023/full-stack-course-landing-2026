# Full Stack Start

A playful, responsive landing page for beginners exploring **the best full stack development course in 2026**. Tap the stack layers, compare MERN, Java and Python, tick off your learning path and jump to live courses and helpful guides.

## Features
- Interactive stack layers, stack comparison tabs and a progress tracker
- Responsive cards, sticky header and full footer
- Accessible: keyboard focus, ARIA tabs, reduced motion support
- Single file, no build step, no dependencies

## Palette
Green `#1B8A52`, Red `#E4474B`, Yellow `#FFC83D`, Lavender `#E9E3FF`

## Run locally
Open `index.html` in any browser.

## Deploy on GitHub Pages
1. Push `index.html` and `README.md` to the repository.
2. Go to Settings, then Pages.
3. Choose branch `main` and folder `/ (root)`, then Save.
4. Your site goes live at `https://<your-username>.github.io/full-stack-course-landing-2026/`.
